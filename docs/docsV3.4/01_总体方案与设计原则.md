## 已明确的设计决定

以下决定在文档迭代过程中已达成共识，实施时应直接遵循：

### 数据源权威：API 是运行时管理路径

详见 [Admin API 总体契约](./07_Admin_API总体契约.md) 第 0 章。核心原则：
- **Admin API 是运行时状态管理的唯一权威路径**
- JSON 配置文件仅做启动加载（"基础设施即代码"基线）
- 运行时 API 的增删改不写回 JSON 文件
- 避免双写冲突

### Phase 4-6 为可选/未来

Registry、ProviderAdapter、TransportAdapter 抽象标记为"可选/未来"：
- Phase 3（Admin API 控制面）已满足生产稳定运行的所有需求
- Phase 4-6 是架构抽象升级，不是稳定生产的前提
- 实施顺序：先做 Phase 0-3 稳定生产，再评估是否有必要引入 Phase 4-6

### WAL 必须有自动轮转

WAL 激活时必须同时实现自动轮转（大小/时间触发），否则会因磁盘写满导致进程 crash。

### 8 个存根文件全部删除

以下 8 个 1 字节/0 字节文件未接入 module 树，全部删除，不保留：

admin.rs, bandwidth.rs, metrics.rs, node_db.rs, node_probe.rs, selector.rs, token_bucket.rs, pool/session.rs

**理由：**
- 留在树中误导后续开发者以为功能已部分实现
- 未声明到 module 树，删除不影响编译
- 若后续需要对应功能，从零创建比基于无用存根更清晰

**执行时机：** Phase 0.5 的第一件事。

### SIGHUP 只重置静态配置，不碰运行时状态

| 重置（从 JSON 配置重新加载） | 不重置（保留运行时状态） |
|---|---|
| Provider/Node/Route/Model 列表 | Pool 分配、健康状态、Ledger 计数 |
| 熔断策略配置 | 进行中的请求 |
| 全局开关默认值 | RingBuffer / WAL / 事件缓冲 |

SIGHUP 不操作 Pool 子池。如需完全重置到配置基线状态，应重启进程。

### 启动环境变量 vs 运行时 API 边界

| 类型 | 定义 | 示例 |
|---|---|---|
| **启动专用** | 进程重启才能生效 | PORT, BIND_ADDRESS, UPSTREAM_BASE, NODES_FILE |
| **运行时 API** | 通过 Admin 端点调用，立即生效 | provider/node 增删改、熔断开关、probe 触发 |
| **混合** | 启动取环境变量值，运行时 API 可覆盖 | OPENCODE_HEADERS_ENABLED, ALLOW_DIRECT_FALLBACK |

混合类配置在启动时加载环境变量作为初始值。Admin API 修改后覆盖内存值。
SIGHUP 时混合类配置重置为环境变量值。

## 2. 每个模块只管自己的事

### 建议边界

| 模块 | 职责 | 不负责 |
|---|---|---|
| models | 模型注册、查询、探测 | 上游请求构造 |
| providers | 上游服务适配 | 网络出口选择 |
| nodes | 网络出口/代理节点管理 | 模型名映射 |
| routes | provider→node 链路绑定 | 请求认证 |
| requests | 请求调用记录 | 实时转发 |
| events | 系统事件 | 业务逻辑 |
| fuse | 熔断状态管理 | 节点调度 |
| health | 健康检查 | 上游业务 |
| metrics | 指标收集 | 事件持久化 |
| config | 配置加载/热加载 | 运行时状态 |

### 当前问题（v3.0）

`proxy.rs` 同时知道：
- opencode 上游 URL 和 API key
- WebShare 代理节点
- OpenCode headers
- 重试策略
- 账本记录
- Pool 状态

v3.4 的目标是逐步解耦。

## 4. 总体设计约束

### P0 约束

- 不引入数据库依赖（P0 用 JSON + WAL + 内存）
- 不依赖外部服务（不依赖 Redis/etcd）
- 不破坏现有路由（兼容旧 API 直到废弃期）
- 不引入 .so/.dll 插件机制（P2 再考虑 WASM）
- 编译通过、测试通过、clippy 不新增警告

### 设计偏好

- 新增功能从 trait 定义开始
- 实现放在`src/`子目录中
- 避免上帝对象（当前 AppState 已有 6 字段，需控制增长）
- 配置从环境变量读取，但支持结构化文件（P1）
- 不提前优化：WAL/RingBuffer 够用就先不上 SQLite
