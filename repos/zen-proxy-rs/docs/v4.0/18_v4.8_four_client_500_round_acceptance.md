# V4.8 Four-Client 500-Round Acceptance

## Purpose

V4.8 defines the 99+ acceptance plan for four real clients:

```text
Windows ClaudeCode
WSL ClaudeCode
WSL OpenClaw
WSL Hermes
```

Each client must execute 500 mixed task rounds through:

```text
client -> NewAPI -> ZenProxyRS -> embedded free-model-client-rs -> proxy node -> upstream
```

Direct ZenProxy calls are allowed only for diagnosis, not for final acceptance.

## Execution Host Rule

All V4.8 link-quality, proxy-pool, NewAPI, ZenProxyRS, and upstream acceptance
tests must run on `panda`.

The local Windows/WSL machine is only a control and documentation workstation.
It must not be used as a proxy-pool quality signal or formal acceptance
execution host.

Reason: Webshare proxy validation on 2026-05-29 showed local Windows/WSL public
IPv4 `154.31.114.217` had `0/100` HTTPS CONNECT success, while `panda` public
IPv4 `43.156.233.219` had `99/100` HTTPS CONNECT success and `99/100`
`opencode.ai` handshake success.

## 99+ Definition

The test passes only if it proves all of the following:

```text
1. Each real client completes 500 task rounds through NewAPI.
2. Each task round can be linked to NewAPI logs, ZenProxy admin/audit rows, client evidence, and pool state.
3. Failures are attributable to client / NewAPI / ZenProxyRS / upstream / proxy pool / model quality.
4. Short requests are not starved by long context, non-stream long output, tools, or subagents.
5. Protocol correctness, tool history, subagent behavior, long-context handling, and security-defense cases are all covered.
6. protocol_first_byte_ms is never reported as real content TTFT.
```

## Test Unit

One client round is one user-visible client task. It may create multiple HTTP
requests, stream chunks, tools, or subagent tasks.

Final reports must count both:

```text
client_task_rounds
newapi_http_requests
zenproxy_requests
tool_calls
subagent_tasks
stream_chunks
errors
```

## Stop Conditions

Pause immediately if any condition occurs:

```text
5xx > 3% for 3 consecutive windows
429 > 20% for 3 consecutive windows
short request P90 first_content > 8s
unattributed empty/no response
tool_call_id/content structural 400
raw stream decode error
ZenProxy RSS monotonically increases for 10 minutes
Redis budget failure or node budget double-spend
dead-pool mis-injury spike
NewAPI rows cannot be reconciled with ZenProxy rows
compactor trims latest user message or recent tool chain
```
